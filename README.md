# SIMPLEIN Solutions Website

This is the official codebase for the [SIMPLEIN Solutions](https://simpleinsolutions.com) corporate website.

## Tech Stack
- **Framework:** [Next.js](https://nextjs.org) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com) v4
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Language:** TypeScript

## Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Run the Development Server**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

3. **Build for Production**
   ```bash
   npm run build
   npm run start
   ```

## Architecture & Design
- **Theme:** Clean, monochrome, premium enterprise design. Fully supports Dark and Light modes automatically.
- **Wordmark:** Fully vector, typographically scalable SVG wordmark that adapts to all devices seamlessly.
- **Components:** Modular React structure located in `src/components/`.
